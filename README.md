# Jean Marc Mbouma’s portfolio

The portfolio is a static site served from `index.html` and `portfolio.css`.
Open `index.html` in a browser or run `python3 -m http.server 8000` from
this directory and visit `http://localhost:8000`.

`policy.html` and `livelink.css` serve the existing JW Attendees privacy policy.
